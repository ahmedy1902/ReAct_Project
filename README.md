# User Management System

A full-stack MERN application for managing users with role-based authentication.

## Features
- User Authentication (Login/Register)
- Role-based Authorization (Admin/User)
- User Profile Management
- Admin Dashboard
- Post Management System

## Technologies
- MongoDB
- Express.js
- React
- Node.js
- Material-UI
- Redux Toolkit
